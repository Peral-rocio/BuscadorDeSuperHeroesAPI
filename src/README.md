  🦸‍♂️ APP BUSCADOR DE SUPERHEROES 🦸‍♀️

 Los Requisitos para aprobar este proyecto son:

 ✅ Crear una aplicación que permita listar superhéroes y obtener información sobre los mismos. Para eso
se utilizará una API REST gratuita con datos reales, donde se podran realizar consultas,  pasandole distintos parametros que permitan personalizar la busqueda y mostrar los datos obtenidos como respuesta. 


 ⭐A demas de lograr que sea una app funcional y nos devuelva la busqueda segun nuestros requerimientos esta app debe:

 🔎 Debe ser responsive
 🔎 Debe cumplir con las funcionalidades principales listadas:
       🔹 Se debe poder realizar una busqueda de superheroes por nombre.
       🔹 Se debe poder ordenera los resultados alfabeticamente, en orden ascendente y descendente al clickear un personaje debe mostrar su informacion completa (con todos los datos traidos de la API)
       🔹 Debe contar con un paginado donde el mismo debe mostrar 20 resultados por pagina, se debe poder ir a la primer pagina, la ultima, la pagina siguiente, y la anterior, y que los botones se desabiliten cuando no puedan ser utilizados. 
🔎 Debe estar deployado y ser accesible desde una dirección web.
🔎 No se debe trabajar en la rama principal alli solo van a mergearse las demás ramas, por lo que cada commit de la misma debería ser el merge de una branch de una funcionalidad terminada.
🔎 Cada funcionalidad que se agregue debe hacerse mediante un PR (Pull Request)



🟢 La API la appi utilizada para este proyecto es la SuperHero API:
https://cdn.jsdelivr.net/gh/akabab/superhero-api@0.3.0/api/all.json
